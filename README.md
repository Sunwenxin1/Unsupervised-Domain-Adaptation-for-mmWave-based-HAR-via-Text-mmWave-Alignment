# TMC-mmUDA

## 论文信息

**论文标题：** Unsupervised Domain Adaptation for mmWave-based HAR via Text-mmWave Alignment

**作者：** Cui Zhao, Wenxin Sun, Han Ding, Ge Wang, Kun Zhao, Wei Xi

**发表期刊：** IEEE Transactions on Mobile Computing (TMC)

---

## 论文简介

本文研究基于毫米波雷达的人体活动识别（Human Activity Recognition，HAR）中的无监督域自适应（Unsupervised Domain Adaptation，UDA）问题，并探索通过文本与毫米波信号对齐来提升跨域识别性能的方法。
